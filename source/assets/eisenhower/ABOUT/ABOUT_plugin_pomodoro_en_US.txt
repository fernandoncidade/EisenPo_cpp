Description:
Natively compiled module inside EisenPo for focused work sessions and short/long breaks with per-task cycle targets (1 to 999 cycles), preventive Cycle Target Warning checks, PoCa sidebar integration, discrete Gantt progress sync, and customizable .wav alarms (via Qt 6.12.0 Multimedia / FFmpeg-n9.0.1 LGPLv2.1+).

Key features:
- Focus, short-break, and long-break cycle timer with smart automatic transitions.
- Customizable per-task cycle targets (1 to 999) plus the preventive Cycle Target Warning modal dialog.
- Lazy initialization of .wav alarm multimedia subsystems ensuring instantaneous application startup.
- Real-time synchronization of ongoing tasks and completed Pomodoro cycles with Eisenhower Matrix and Gantt.

Native Architecture & Local-First Data Sovereignty (100% Offline):
- All modules (Eisenhower, Pomodoro, Feynman, Agenda, and Gantt & 4D BIM) are compiled natively into a single Windows x64 executable (C++ / Qt 6.12.0), with zero external plugin DLLs and zero telemetry.
- Timers, cycle targets, completed session counters, and alarm preferences operate 100% locally in memory and under %LOCALAPPDATA%\EisenPo\tarefas.json and layout.json, with zero network traffic.
- Clean uninstallation guaranteed via Windows Settings or the Start Menu without leaving background services running.
