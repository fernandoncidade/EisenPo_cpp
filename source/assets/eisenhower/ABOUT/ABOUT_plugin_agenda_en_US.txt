Description:
Natively compiled module inside EisenPo dedicated to academic and professional Activity Registration (course, syllabus, semester, subject, class, assessment category, dates, times, and grades), featuring hierarchical custom agendas, independent color modes, and local SQLite persistence (listas.db).

Key features:
- Structured assessment logging directly synced into unified tasks in tarefas.json.
- Custom hierarchical tree schedules saved under agendas/*.json with referential integrity on deletion.
- Embedded local SQLite database (listas.db) with freeze-free in-memory loading.
- Independent color theme controls (theme-adaptive Black and Colorful) stored in agenda_config.json.

Native Architecture & Local-First Data Sovereignty (100% Offline):
- All modules (Eisenhower, Pomodoro, Feynman, Agenda, and Gantt & 4D BIM) are compiled natively into a single Windows x64 executable (C++ / Qt 6.12.0), with zero external plugin DLLs and zero telemetry.
- Activity records, subject lists, custom agendas, and display preferences stay solely inside %LOCALAPPDATA%\EisenPo (listas.db, agenda_config.json, agendas/*.json, and tarefas.json), with zero external transmission.
- Clean uninstallation guaranteed via Windows Settings or the Start Menu without leaving background services running.
