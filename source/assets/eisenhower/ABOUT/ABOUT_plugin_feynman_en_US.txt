Description:
Natively integrated module in EisenPo implementing the Feynman Technique for active learning through structured steps (concept, plain-language teaching, gap identification, and review/mastery), featuring customizable step labels, local study file linking, and live UnifiedTaskStore synchronization.

Key features:
- Structured Feynman Method stages supporting Tabs, Vertical, and Horizontal viewing arrangements.
- Full customization of stage labels under Settings > Edit Labels (persisted in feynman_rotulos_config.json).
- Local study document linking (PDFs, notes, references) opened strictly upon user click.
- Bidirectional synchronization of concepts and mastery levels with Eisenhower Matrix tasks.

Native Architecture & Local-First Data Sovereignty (100% Offline):
- All modules (Eisenhower, Pomodoro, Feynman, Agenda, and Gantt & 4D BIM) are compiled natively into a single Windows x64 executable (C++ / Qt 6.12.0), with zero external plugin DLLs and zero telemetry.
- Study concepts, explanations, identified gaps, mastery levels, linked local file paths, and custom labels remain strictly local inside %LOCALAPPDATA%\EisenPo (tarefas.json and feynman_rotulos_config.json).
- Clean uninstallation guaranteed via Windows Settings or the Start Menu without leaving background services running.
