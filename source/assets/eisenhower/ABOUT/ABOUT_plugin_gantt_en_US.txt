Description:
Natively integrated module in EisenPo structured in 4-layer Clean Architecture providing hierarchical WBS/EAP tables, interactive Gantt timelines with unified status colors and runtime-retranslatable tooltips, analytical DAG Critical Path Method (CPM) engine with cycle protection, WorkCalendar and 18-country Holiday Manager (Meeus/Jones/Butcher), Baselines, Ghost Line overlays, and 4D BIM construction simulation persisted locally in SQLite (eisenpo_gantt.db).

Key features:
- DAG Critical Path Method (CPM) solver computing early/late dates and free/total floats across FS, SS, FF, and SF dependencies.
- 5 persistent layout modes in layout.json, balanced 50%/50% WBS/Gantt splits, and bi-directional column resizing.
- Discrete Pomodoro-driven physical progress (completed / estimated cycles) and live runtime-retranslatable timeline tooltips.
- Custom WorkCalendar + 18-country Holiday Manager featuring Meeus/Jones/Butcher movable Easter calculation.
- 4D BIM timeline simulation mapped to IFC GUID / UniqueId, O(1) Eisenhower Matrix sync, and CSV import/export.

Native Architecture & Local-First Data Sovereignty (100% Offline):
- All modules (Eisenhower, Pomodoro, Feynman, Agenda, and Gantt & 4D BIM) are compiled natively into a single Windows x64 executable (C++ / Qt 6.12.0), with zero external plugin DLLs and zero telemetry.
- Schedules, WBS items, costs, dependencies, baselines, work calendars, 4D links, and caches remain strictly local inside %LOCALAPPDATA%\EisenPo (eisenpo_gantt.db and layout.json). Dormant code under Gantt/api/ is never instantiated at runtime, guaranteeing 100% offline operation and zero network traffic.
- Clean uninstallation guaranteed via Windows Settings or the Start Menu without leaving background services running.
