Description:
EisenPo is a native Windows desktop application built with modern C++ and Qt 6.12.0 for strategic task organization using the Eisenhower Matrix (Important x Urgent), natively integrating Pomodoro, Feynman active learning, Agenda (Activity Registration), and Gantt & 4D BIM scheduling directly inside the main executable.

Key features:
- Four-quadrant Eisenhower Matrix (Pending, In Progress, Completed), Tabbed/Quadrants/2x2 and PoCa (2xK) layouts.
- Ergonomic 3-row New Task bar with Duration in days, responsive EditTaskDialog, and monthly/annual calendars.
- Pomodoro Module: focus/break timers, per-task cycle targets (1-999), Cycle Target Warning, and lazy-loaded .wav audio alarms.
- Feynman Module: 5-step active study workflow with customizable step labels and local study file attachments.
- Agenda Module: academic/professional activity logging and hierarchical schedules stored in local SQLite (listas.db).
- Gantt & 4D BIM Module: WBS/EAP tree, analytical DAG Critical Path Method (CPM), WorkCalendar, 18-country Holidays (Meeus/Jones/Butcher), Baselines/Ghost Line, 4D simulation (eisenpo_gantt.db), and CSV exchange.
- Local import/export (JSON, CSV, XLSX, PDF, ICS) and instant runtime English/Portuguese switching.

Native Architecture & Local-First Data Sovereignty (100% Offline):
- All modules (Eisenhower, Pomodoro, Feynman, Agenda, and Gantt & 4D BIM) are compiled natively into a single Windows x64 executable (C++ / Qt 6.12.0), with zero external plugin DLLs and zero telemetry.
- All tasks (tarefas.json), UI settings (layout.json, language.json, fonts), Feynman labels (feynman_rotulos_config.json), Agenda SQLite database (listas.db and agendas/*.json), Gantt SQLite database (eisenpo_gantt.db), and diagnostic logs (logs/file_eisenpo_*.log) stay strictly on disk inside %LOCALAPPDATA%\EisenPo on the user's device.
- Clean uninstallation guaranteed via Windows Settings or the Start Menu without leaving background services running.
