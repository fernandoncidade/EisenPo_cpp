Description:
Core host of EisenPo providing the Eisenhower Matrix (Important x Urgent), atomic unified persistence (UnifiedTaskStore in tarefas.json), integrated calendars, global search, advanced filters, batch recurrences, local reminders, import/export (JSON, CSV, XLSX, PDF, ICS), and native orchestration of Pomodoro, Feynman, Agenda, and Gantt & 4D BIM.

Key features:
- Four strategic quadrants tracking Pending, In Progress, and Completed tasks.
- Five workspace modes (Tabbed Horizontal/Vertical, Quadrants, 2x2 Matrix, and PoCa 2xK unified sidebar).
- 3-row New Task bar with Duration in days and dual-mode responsive EditTaskDialog with anti-flicker hysteresis.
- Safe local file linking via file dialog or drag-and-drop (opened solely upon explicit user click).
- Productivity suite: Global Search (Ctrl+Shift+G), Today/Next 7 Days (Ctrl+Shift+H), Filters (Ctrl+Alt+F), Recurrences, Local Reminders, and Spaced Reviews.

Native Architecture & Local-First Data Sovereignty (100% Offline):
- All modules (Eisenhower, Pomodoro, Feynman, Agenda, and Gantt & 4D BIM) are compiled natively into a single Windows x64 executable (C++ / Qt 6.12.0), with zero external plugin DLLs and zero telemetry.
- Core host tasks and UI preferences reside exclusively in %LOCALAPPDATA%\EisenPo (tarefas.json, layout.json, language.json, recorrencias_*.json, lembretes_locais_config.json, *_font_config.json, and logs/file_eisenpo_*.log), transparently migrating legacy EisenhowerOrganizer folders.
- Clean uninstallation guaranteed via Windows Settings or the Start Menu without leaving background services running.
